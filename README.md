## PFMEA (Process Failure Mode and Effects Analysis)

| Failure Mode | Effect | Cause | Control |
|---|---|---|---|
| Nest wears oversized | False acceptance for parts (part sitting loosely will be interpreted as in-spec when it's actually oversized) | Part wears the nest down over time with friction and repeated cycles | Periodic gauge calibration/inspection schedule |
| Debris/buildup in nest reduces effective size | False rejections (part cannot fully seat, appears out-of-spec) | Dirty bench station (part residue, not cleaned between uses) | Visual/tactile check of nest before any use |
| Gauge pin measuring step is skipped | False acceptance/rejection for parts (out-of-spec parts are not checked) | Rushing, unclear instructions, pin misplaced | Standardize work instruction requiring gauge check before sign-off |
| Part is seated wrong | False rejections/acceptance (misalignment can distort in-spec and out-of-spec) | Operator is distracted, no positive locating feature beyond nest fit | Visual check before use, consistent seating method |
| Wrong gauge pin end is used | False rejections/acceptance (wrong limit checked) | Operator is unfamiliar with go/no-go conventions, operator is distracted, no clear labeling | Label go/no-go ends clearly |
| Gauge pin is worn | False rejections/acceptance (drift in acceptance window narrows/widens from 4.19–4.35mm) | Wear over time from repeated use | Regular calibration, replace at wear limit |
| Gauge is misread/misinterpreted | False reject/acceptance | Operator is distracted, poor lighting, inconsistent training | Standardize work instruction; training with a second check if critical |
